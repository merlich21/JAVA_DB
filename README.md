Мини-приложение «Пользователи и БД»
Необходимо реализовать простое консольное Java-приложение, которое работает с базой данных PostgreSQL через JDBC.
Приложение должно:
1. Подключаться к базе данных PostgreSQL.
2. Работать с таблицей пользователей.
3. Использовать паттерн DAO.
4. Выполнять чтение и добавление данных в БД.
5. Использовать PreparedStatement.

«Управление заказами пользователей»
Условие
Необходимо реализовать Java-приложение, которое работает с таблицей заказов пользователей в базе
данных PostgreSQL.
Каждый заказ:
● принадлежит конкретному пользователю;
● имеет сумму и дату создания.

Требования к программе
Программа должна уметь:
1. Добавлять новый заказ пользователю
2. Получать список заказов конкретного пользователя
3. Получать общую сумму заказов пользователя
4. Выводить результат работы в консоль
Обязательные условия:
● использовать PreparedStatement;
● использовать паттерн DAO;
● соединение с БД закрывать корректно
